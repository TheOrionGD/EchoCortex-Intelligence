# UI Design Guidelines

## Philosophy
The Echo UI represents "Institutional Clarity." It is designed to feel like a high-security terminal rather than a consumer app.

## Color Palette
- **Obsidian (#050505)**: Primary background. Deep space.
- **Carbon (#121212)**: Secondary background. Component surfaces.
- **Stark (#FAFAFA)**: Primary text. High readability.
- **Accent (#4F46E5)**: Interactive elements and data highlights (Indigo-600).
- **Alert (#DC2626)**: Destructive actions and stream termination.

## Typography
- **Sans**: `Inter`. Used for general UI, labels, and metadata.
- **Mono**: `JetBrains Mono`. Used for technical identifiers, timestamps, and system logs.
- **Serif**: (System default italic). Used for blockquotes and semantic search results to denote "quoted memory."

## Components
- **Buttons**: All caps, 0.25em tracking, monospaced for 'lg' variants.
- **Borders**: 1px solid `#18181B` (Zinc-900) for standard containers.
- **Animations**: Subtle `fade-in` and `slide-up` (700ms) to simulate a "loading OS" feel.
